# 🌍 Climate Trend Analyzer

## 📌 Overview
A data science project that analyzes climate data to identify trends, detect anomalies, and forecast future temperature patterns using machine learning.

---

## 🎯 Problem Statement
Understanding climate change requires analyzing long-term environmental data. This project simulates real-world climate analysis by identifying temperature trends and unusual climate behavior.

---

## 🚀 Features
- 📈 Trend Analysis using Rolling Mean & Regression
- ⚠️ Anomaly Detection using statistical methods
- 🔮 Forecasting future temperature values
- 📊 Data Visualization using matplotlib
- 📁 Exportable outputs for analysis

---

## 🛠️ Tech Stack
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
